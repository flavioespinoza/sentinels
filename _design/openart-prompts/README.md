# OpenArt Prompts -- Sentinels Portrait Set

Ten portraits, one roster. Paste the **SHARED STYLE BLOCK** at the start of every prompt, then append the character-specific block. This keeps the ten portraits coherent enough to read as a team.

---

## SHARED STYLE BLOCK

Paste this verbatim before each character prompt:

```txt
Dark sci-fi concept art, hard-surface mech design, single character study, full figure, three-quarter angle, slight upward camera tilt. Style: painted digital art, detailed metallic panels, subsurface glow from eye element, dramatic rim lighting from above and behind, single saturated accent glow against a near-black environment. Background: industrial dark #0d0f14, heavy atmosphere, faint depth-of-field blur on background geometry. Body: angular armored plates, dark gunmetal and charcoal tones, no organic forms, no humans, purely mechanical. The character stands in a guard stance. Aspect ratio 3:4.
```

## Three Variations Per Character

Each prompt file specifies three variations. Submit all three to OpenArt and pick the strongest. Variations differ in:
- **V1**: standard guard stance, direct camera angle
- **V2**: slight side turn, one shoulder closer to viewer
- **V3**: close-up three-quarter, cropped at mid-torso, eye glow prominent

Keep the same style block for all three.
